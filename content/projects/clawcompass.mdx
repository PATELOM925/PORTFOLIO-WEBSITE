## What I built

- Routed agent requests to ranked capabilities based on task, context, budget, and constraints.
- Redacted secret-like inputs before recommendation and execution.
- Enforced payment and explicit-approval gates before protected actions.
- Built buyer, seller, transaction, security, and reputation views for the demo workflow.

## Hackathon context

ClawCompass was built for the OpenClaw / GOAT Toronto Tech Week hackathon. External wallet, x402, and mainnet registration steps stayed behind explicit approval gates.

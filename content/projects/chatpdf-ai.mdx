## Highlights
- Built a retrieval-first document QA system using LangChain + FAISS to ground answers in source text.
- Integrated OpenAI Agents SDK for agentic workflows in document querying and response generation, resulting in 80% accuracy on a manual test set (N ≤ 50). Deployed on Streamlit.

## Core build
This project combines LangChain document chunking, embedding-based FAISS vector search, and OpenAI Agents SDK workflows for querying and answer generation in a Streamlit app.

## What I learned
- Chunking strategy affects answer quality more than people expect.
- Retrieval quality limits answer quality; the model cannot recover from weak context.
- Retrieved passages should remain inspectable when assessing an answer.
